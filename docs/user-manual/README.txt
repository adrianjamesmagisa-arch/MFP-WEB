PCC MFP Web — Encoder User Manuals
==================================

Thank you for helping encode monitoring data for your center. These guides
explain what to type, what the system calculates for you, and how to use
buttons such as “Add delivered-as-of date.”

WHICH MODULE SHOULD I USE?
--------------------------
• DepEd (School-Based Feeding Program)  →  use **SBFP** in the sidebar.
• DSWD (Supplementary Feeding Program)   →  use **DSWD** under Program monitoring.

Other funders (LDS, LGU, Others) have their own monitoring menus; this folder
focuses on DepEd (SBFP) and DSWD as requested.

FILES IN THIS FOLDER
--------------------
• SBFP-DepEd-Encoder-Manual.txt   — Full guide for DepEd / SBFP encoders
• DSWD-Encoder-Manual.txt         — Full guide for DSWD encoders
• centers\<CENTER>-Encoder-Welcome.txt — Short welcome for each PCC center
  (where to sign in, which module to open, link to the full guides)

PCC CENTERS (profile / encoder home)
------------------------------------
MMSU, CSU, CMU, DMMMSU, LCSF, CLSU, MLPC, UPLB, USF, USM, VSU, WVSU, NHQGP (NIZ)

If your account is tied to one center, the sidebar usually opens your center
directly. You may still read the full manuals for formulas and column rules.

Questions or corrections? Please contact your center coordinator or PCC IT support.
